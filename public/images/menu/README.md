# Menu photos

Each SVG is an individual dark placeholder. Put your downloaded JPG, PNG, or WebP photos in this folder, then update the matching `image` path in `src/data/menu.js` (for example `/images/menu/dragon-sushi.webp`).

Keep photos near the 900 × 650 aspect ratio for consistent rows. Update the image alt text in `src/components/menu.jsx` when replacing placeholders. Prices and ingredient lists are editable in `src/data/menu.js`; wine prices are glass / bottle.
